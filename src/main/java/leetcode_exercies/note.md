🧩 1️⃣ DẠNG HASHMAP / HASHSET (tra cứu nhanh, đếm, ghép cặp)
Tư duy chính:
→ Dùng map/set để tra cứu nhanh (O(1)), đếm tần suất, hoặc tìm phần tử liên quan (complement).


🧮 2️⃣ DẠNG MẢNG (Array)
Tư duy chính:
→ Duyệt, tìm max/min, xử lý theo index, 2 con trỏ, prefix sum.


🧠 3️⃣ DẠNG CHUỖI (String)
Tư duy chính:
→ Duyệt từng ký tự, xử lý substring, reverse, hoặc dùng HashMap đếm ký tự.


🪟 4️⃣ DẠNG SLIDING WINDOW (cửa sổ trượt)
Tư duy chính:
→ Dùng 2 con trỏ (left, right) để kiểm soát vùng (window) và cập nhật kết quả.


🔁 5️⃣ DẠNG TWO POINTER (2 con trỏ)
Tư duy chính:
→ Dùng khi mảng đã sắp xếp hoặc khi cần so sánh 2 phía.


🧱 6️⃣ DẠNG STACK / QUEUE
Tư duy chính:
→ Dùng stack để xử lý dạng lùi (backtrack) hoặc phân tích biểu thức, queue cho BFS.


🌳 7️⃣ DẠNG TREE (cây nhị phân)
Tư duy chính:
→ Duyệt đệ quy (DFS, BFS), xử lý node trái–phải, hoặc tính độ cao.


🔗 8️⃣ DẠNG LINKED LIST
Tư duy chính:
→ Duyệt node, đảo ngược, tìm giữa, ghép nối.


🔢 9️⃣ DẠNG SORTING & SEARCHING
Tư duy chính:
→ Tìm kiếm nhị phân hoặc sắp xếp tùy điều kiện.


🧩 🔟 DẠNG DYNAMIC PROGRAMMING (DP)
